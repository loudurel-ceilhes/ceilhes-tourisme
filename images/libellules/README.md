## Préparation et usage

Les deux photographies ont été inspectées visuellement. Chaque vue possède
trois variantes WebP (`-640`, `-1000`, `-1600`, qualité 78) et un JPEG progressif
de repli (qualité 82), côté long maximal de 1600 px. Seuls le redimensionnement
et la compression ont été appliqués ; cadrage et contenu sont conservés.

Usage : `hebergeurs.html#libellules`, avec une légende identifiant le bon gîte,
une attribution visible et un rappel dans les mentions légales. Les liens vers
les deux galeries officielles restent disponibles pour voir les autres photos.
