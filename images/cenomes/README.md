# Photographie de la mine de Cénomes

Crédit à reproduire exactement : **© AAlliès_Mine de Cénomes_2024**.

Le 15 novembre 2026, Lou a transmis le message de Christel et Serge autorisant
l’utilisation de trois photographies pour illustrer la présentation de la mine
sur le site, ainsi que le choix d’une sélection parmi ces trois images.
La présentation existante leur convient ; son texte est conservé.

La photographie retenue est la deuxième des trois vues transmises : un groupe
de visiteurs casqués dans une galerie, devant une ouverture maçonnée.
Elle a été retrouvée à l’identique sur le site officiel de la mine :

- Source : https://minecenomes.fr/wp-content/uploads/2024/04/%C2%A9AAllies_Mine-de-Cenomes_2024_IMG_6545-scaled.jpg
- Référence du média public : `IMG_6545` (média WordPress 303).
- Fichier source téléchargé : 2560 × 1707 pixels.
- Usage : `alentours.html#mine-cenomes`, crédit visible sous la photo et rappelé
  dans les mentions légales.

Les fichiers `visite-galerie-*` sont des exports WebP aux largeurs de 640,
1000 et 1600 pixels, avec un repli JPEG de 1600 pixels. Seuls le redimensionnement
et la compression ont été appliqués, sans recadrage ni modification du contenu.
L’autorisation ne vaut pas pour l’ensemble des photographies du site officiel.
